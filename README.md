# HeyTuber

**A Lightweight PNGTuber App for Windows.**

## Project Overview

<img width="1367" height="821" alt="{C7760366-FA39-44EF-A764-C38B9BB06B98}" src="https://github.com/user-attachments/assets/aec7209e-3a07-4c9e-ac78-0617fbf0e47c" />


HeyTuber is a lightweight desktop application designed for PNGTuber creators.

It allows users to control and animate their PNG avatars using microphone voice detection, making virtual streaming simple and accessible.

## Features

- PNG Avatar Support
- Microphone-Based Voice Detection
- Automatic Avatar Expression Switching
- Lightweight Performance
- Simple User Interface
- Local Processing
- Windows Desktop Support

## Platform

- Windows 10 / 11
- Desktop Application

## Installation

1. Download the latest HeyTuber release.
2. Extract the downloaded files.
3. Open the application folder.
4. Run `HeyTuber.exe`.
5. Start using your PNG avatar!
